| 论文标题 | Zephyr：面向长文档问答的分层记忆压缩 |
| 作者 | Li Ming、Wang Fang |
| 发表年份 | 2024 |
| 研究问题 | 能否在不训练新参数的前提下把长文档上下文压到可控预算，且不显著损害问答质量 |
| 研究方法 | 按语义相似度切分文档构建语义块；为每块生成粗粒度与细粒度两种表示，查询时先粗筛再精排；最后按边际增益贪心选择块直到预算用尽 |
| 主要发现 | 端到端延迟降低约四成；召回率相对全文拼接仅下降一点二个百分点；去掉关键词倒排表会损失约三个百分点召回率 |
| 创新点 | 全流程不更新编码器参数；把双粒度索引与贪心压缩组合成可直接套用的检索管线 |
| 局限性 | 只在英文抽取式问答上验证；首次建索引的时间开销不可忽略；权重与预算需人工调整 |
| 与本研究的关联 | 未提及 |
