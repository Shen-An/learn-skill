# SAM 论文笔记索引

论文：Segment Anything（ICCV 2023，arXiv:2304.02643，Alexander Kirillov 等）

一句话结论：把图像分割从"每个任务一版模型"改写成可提示的分割基础模型：用 1100 万张图、10 亿个掩码的 SA-1B 数据与一个轻量提示编码器加掩码解码器，让点、框、文本提示都能在零样本下出掩码，代价是数据引擎与标注规模难以复现，且论文自述对细粒度结构与语义歧义提示仍会出错。
