# 输入接入规范（PDF / 摘要 / DOI / 二手转述）

论文笔记的可靠性上限由**能拿到什么材料**决定。本文件规定各类输入怎么接、接到什么深度、以及怎么把来源钉到可回溯的位置。

## 一、输入类型与接入路径

| 输入 | 接入方式 | 能讲到什么深度 |
|------|---------|---------------|
| 工作区内 PDF 路径 | harness 文档读取能力（DSH 用 `read_document`，支持 `offset`/`limit` 分页）或 `python scripts/pdf_extract.py <pdf> --out <输出目录>/_source/` | 全文：方法、实验、消融、超参、局限 |
| `.dsh-uploads/<sessionId>/` 下的上传件 | 同上；上传目录里的文件用 `read_document` 读，不要用普通文本读 | 同上 |
| 扫描件 / 图片型 PDF | 先按 PDF 提取；若整页无可提取文本层，走 OCR（harness 的 OCR 能力或 `read_image` + OCR），并在笔记里标注 `[OCR]` | 正文可用，但公式与数字需人工复核 |
| DOI / arXiv 链接 / 标题 | 检索取官方摘要与元数据（作者、年份、发表处）；正文仍需用户提供 | 问题、机制大意、主结果口径；**不得**讲公式细节与消融 |
| 只有他人总结（博客、AI 转述） | 直接按 `[二手]` 接入，数字一律标"待核对" | 只能转述到"二手说了什么" |
| 官方代码仓库 | 读源码与 README，用于核实默认超参、实现细节、与论文表述的差异 | 实现事实（默认值、控制流），**不得**据此推断论文动机 |

## 二、PDF 导入的固定流程

1. **落盘**：把 PDF 正文转成 Markdown 放到 `<输出目录>/_source/<论文名>.md`，保留页锚点。
2. **分页阅读**：长文档按 `offset`/`limit` 分页读完，不要只读前几页就开始写。
3. **页锚点**：PDF 里每一页对应 `<!-- page:N -->`。正文引用写成 `[原文 p.12]`，让读者能直接翻页核对。
4. **扫描件标注**：OCR 得到的文本标 `[OCR]`，并在「证据与出处」写明"OCR 文本，公式与数字存在识别风险"。
5. **不覆盖原件**：提取产物只写在 `_source/` 下，不改动用户给的 PDF。

`pdf_extract.py` 的退出码：`0` 成功；`2` 参数错误（页码范围非法）；`3` 缺依赖（`pypdf`/`PyPDF2` 都没装）；`4` PDF 已加密。

## 三、必须落纸的声明

「证据与出处」小节的第一行必须写来源类型，取值从下列枚举里挑（多项用 ` + ` 连接）：

- `PDF 全文`——拿到了全文正文
- `官方摘要`——只有出版社/arXiv 摘要
- `二手转述`——他人总结、博客、AI 总结
- `代码`——官方实现
- `OCR`——扫描件识别文本

写法示例：

```text
**来源类型**：PDF 全文（`_source/attention-is-all-you-need.md`，共 15 页）+ 代码
```

**声明了 `PDF 全文` 就必须出现页码锚点**（至少一处 `[原文 p.12]` 形式），否则机械校验报 `W-DEEP-PAGE`——这条规则的作用是防止"声称读了全文、实际只看了摘要"。

## 四、材料不足时的动作

材料不够就不要硬讲：

1. 在交付开头一句说明"手上只有 X，因此只能讲到 Y 层"，并列出需要什么才能补全。
2. 把做不到的部分写进「未核实 / 未提及」，并给出可核查入口（DOI、文件名、页码、源码路径）。
3. **禁止**用领域常识把缺口填成论文主张；**禁止**把二手转述的细节讲成原文结论。
