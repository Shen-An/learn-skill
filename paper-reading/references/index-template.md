# 论文库索引模板（模式 G：合集层）

**产物**：`paper-notes/README.md`——一个笔记库一份，随论文累积而**生长**。

单篇笔记回答"这篇论文讲了什么"；库索引回答"**我读过哪些论文、各自结论是什么、彼此在哪里冲突、我的证据只到哪一层**"。它不是文件清单，而是可增量续写的合集层：新论文只追加条目、补术语、补对比，**不推倒重来**。

机械校验：`python scripts/check_paper_note.py paper-notes/README.md --mode index`。**校验索引一律用显式 `--mode index`**——`--mode auto` 只认首行标记，标记写错或丢失时它不会把文件当成索引，而是退回深读模式报一堆 `E-DEEP-SUM` / `E-DEEP-SEC`，反而看不出真正病因（此行为已实测确认）。

## 1. 骨架（顺序与标题不得改）

```markdown
<!-- paper-reading: collection-index -->
# <研究方向>论文笔记库

> 最近更新：YYYY-MM-DD ｜ 收录 N 篇 ｜ 覆盖范围：一句话说清这批论文共同回答什么问题

## 一、主题清单

### <主题名 1>
- [<短名>](./<短名>/README.md) — <一句话结论>（证据：<类型>；代码：<有|无>）
- [<短名>](./<短名>/README.md) — ……

### <主题名 2>
- ……

## 二、术语速查

| 术语 | 一句话解释 | 首次出现 |
|------|-----------|---------|
| <术语> | <面向"有通用基础、无小方向基础"的读者的一句话> | <短名> |

## 三、跨论文对比

| 维度 | <短名 A> | <短名 B> | 结论 |
|------|---------|---------|------|
| <同一指标或同一机制> | <数字/设定> | <数字/设定> | 一致 / 冲突（待核对） |

## 四、未解决问题

- **论文自述**：<原文 limitation>（来源：<标记>）
- **我的疑问**：<基于笔记能推出的疑问>（[推断]）

## 五、证据强度总览

| 短名 | 来源类型 | 可复现性 | 待核对项 |
|------|---------|---------|---------|
| <短名> | PDF 全文 / 官方摘要 / 二手转述 | 有官方代码 / 无 | <二手数字等> |
```

## 2. 条目形状（硬约束）

```
- [<短名>](./<短名>/README.md) — <一句话结论>（证据：<类型>；代码：<有|无>）
```

- 链接**目标路径**里的 `<短名>` 必须与磁盘上的目录名一致，且必须**真实可达**（`E-IDX-LINK` 拦死链）；链接**文本**建议就用短名（方便和目录名对照），但允许加副标题装饰，校验器不管这一项。
- ` — `（空格 + 破折号 + 空格）是结论分隔符，缺了报 `E-IDX-ENTRY`。
- `<类型>` 只能取 `全文` / `摘要` / `二手` / `代码` / `OCR`（与 `references/grounding-rules.md` 的分层同源，不得造新词）。
- 结论里出现的每个数字都要能在该论文笔记里找到同源标记；**不许**把二手数字升级成"论文证明"。

## 3. 五个小节的写法

| 小节 | 写什么 | 不写什么 |
|------|--------|---------|
| 一、主题清单 | 按主题分组的论文条目；分组名用领域说法，不用"其他" | 文件清单、目录树、进度状态 |
| 二、术语速查 | 只在最早出现的那篇下的术语；一句话讲清"与相邻概念差在哪" | 术语的完整定义、公式 |
| 三、跨论文对比 | 同一维度上各论文的设定与数字并列 | 只有一篇论文时不要硬编对比（写一行"目前仅 1 篇，待补充"即可） |
| 四、未解决问题 | 论文自述的 limitation 与你的疑问**分开**列 | 把"我没想到"写成"论文没做" |
| 五、证据强度总览 | 每篇的来源类型、可复现性、待核对项 | 空表 |

## 4. 增量续写规则

1. **追加而不重排**：新论文只在对应 `### <主题>` 下加一行；没有合适主题就新开一个 `###`，不动已有分组顺序。
2. **同步元信息**：更新 `> 最近更新：` 日期与`收录 N 篇`。
3. **术语表只增不删**：同一术语被多篇用到时，"首次出现"保留最早那篇。
4. **数字冲突必须并列**：新论文与已有论文在同一指标上不一致 → 两列都写 + 结论列标"冲突（待核对）"；**禁止**取平均、禁止只留一个、禁止沉默（与 SKILL.md 规则 1 同源）。
5. **改旧结论要留痕**：已有条目的结论因新证据变化时，就地改写并在行末加 `（更新：YYYY-MM-DD，原因）`。
6. **删改笔记要同步索引**：单篇笔记改名/删除后立刻改索引，不留死链。

## 5. 机械校验的 10 个检查码

| CODE | 级别 | 含义 |
|------|------|------|
| `E-IDX-MARKER` | ERROR | 首行非空内容不是 `<!-- paper-reading: collection-index -->`（只在显式 `--mode index` 下报：auto 正是靠这行识别索引，缺了它文件根本不会被当成索引） |
| `E-IDX-H1` | ERROR | 缺唯一 H1（形如 `# <方向>论文笔记库`） |
| `E-IDX-SEC` | ERROR | 五个必备二级小节缺失或顺序不对 |
| `E-IDX-LINK` | ERROR | 条目链接目标文件不存在 |
| `E-IDX-ENTRY` | ERROR | 条目不符合规定形状（缺链接 / 缺 ` — ` / 缺证据括注） |
| `E-IDX-DUP` | ERROR | 同一篇论文被登记两次 |
| `E-IDX-SRCKIND` | ERROR | 证据类型不在 {全文, 摘要, 二手, 代码, OCR} 内 |
| `W-IDX-ORPHAN` | WARN | 同级子目录里有 `<子目录>/README.md` 但未被索引登记（漏登记） |
| `W-IDX-TERM` | WARN | 术语速查表不是三列 `术语 / 一句话解释 / 首次出现`，或没有数据行 |
| `W-IDX-UPDATE` | WARN | 缺 `> 最近更新：YYYY-MM-DD` 行 |

## 6. 常犯的错

- 把索引写成**文件清单**（只有链接、没有结论与证据）→ `E-IDX-ENTRY`。
- 用**二手转述**当条目结论却不标"二手"→ `E-IDX-SRCKIND`（或人工项，见 `quality-rubric.md` 的 H 节）。
- 新笔记写完了**忘了登记** → `W-IDX-ORPHAN`。
- 复制上一篇的索引改内容，**忘了改日期** → `W-IDX-UPDATE`。
- 跨论文对比里把两个不一致的数字**只留一个** → 机器查不出，人工项必查（H 节）。
